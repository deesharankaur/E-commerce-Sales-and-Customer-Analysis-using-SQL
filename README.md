# E-commerce Sales Analysis using SQL

## About the Project
This project analyzes online retail transaction data using SQL to identify sales trends, top-performing products, valuable customers, and country-wise revenue.

## Tools Used
- SQLite
- SQL
- GitHub

## Key Analysis
- Overall revenue and total orders
- Top 10 products by revenue
- Country-wise sales performance
- Monthly revenue trends
- Top customers by spending
- Repeat customer analysis
- Data cleaning and quality checks

## Dataset
The project uses the [UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail).

## Skills Demonstrated
SQL queries, aggregate functions, GROUP BY, CTEs, subqueries, and window functions.

## Goal
To practice real-world data analysis and develop practical SQL skills for Data Analyst.
